StokLedger Pro Ultima v1.9.4

PERUBAHAN:
1. Menu Sistem > Lokasi Database & Backup menampilkan lokasi database aktif.
2. Menampilkan lokasi folder backup otomatis.
3. Backup SQLite konsisten dibuat setiap aplikasi/server ditutup secara normal.
4. Maksimal 30 backup terbaru disimpan; backup lebih lama dibersihkan otomatis.
5. Folder backup installer: C:\ProgramData\StokLedger Pro Ultima\backups

CATATAN:
Backup otomatis membutuhkan proses penutupan normal. Jika komputer mati paksa atau proses dihentikan paksa, backup saat penutupan tidak dapat dijalankan.
