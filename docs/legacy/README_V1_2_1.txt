STOKLEDGER PRO SERVER CORE v1.2.1 - MODERN SIDEBAR UI
=======================================================

PERUBAHAN UI
- Sidebar tetap di sebelah kiri seperti StokLedger Standard
- Menu dikelompokkan: Utama, Master Data, Transaksi, Akuntansi, Sistem
- Area kerja teratur di sebelah kanan
- Status user dan server tampil di sidebar
- Tampilan tabel, form, kartu statistik dan tombol lebih modern
- Navigasi responsif untuk layar kecil
- Tidak ada perubahan database atau logika transaksi

MIGRASI
1. Tutup server v1.2.0.
2. Backup data\stokledger_pro.db.
3. Salin database ke folder data v1.2.1.
4. Jalankan TEST_SERVER.bat.
5. Jalankan START_SERVER.bat.
6. Tekan Ctrl+F5 pada browser.
