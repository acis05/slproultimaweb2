STOKLEDGER PRO v1.3.4 - FIXED NAVIGATION & PDF IMPORT
=====================================================

PERBAIKAN:
1. Data Pelanggan dan Pemasok memiliki halaman terpisah, label jelas,
   serta kolom Saldo Awal Piutang / Saldo Awal Hutang.
2. Master Data memiliki kartu Data Merk tersendiri.
3. Modul Penjualan tidak lagi memiliki kartu Nota dan Surat Jalan
   terpisah. Cetak dilakukan dari Daftar Penjualan.
4. Modul Pembelian tidak lagi memiliki kartu Faktur dan Good Receive
   terpisah. Cetak dilakukan dari Daftar Pembelian.
5. Smart Import membaca PDF rekening koran BCA dan menampilkan preview.
6. Riwayat Kas & Bank hanya menampilkan tabel riwayat.
7. Kartu & Saldo Stok serta Transfer Gudang dibuka terpisah.
   Reminder dan Dead Stock tetap berada di Dashboard.
8. Menu Akuntansi hanya menampilkan bagian yang dipilih.
9. Preview cetakan diperbaiki dengan token sesi pada URL cetak.

PDF SUPPORT:
Jalankan INSTALL_PDF_SUPPORT.bat sekali pada komputer server.
Fitur PDF saat ini mendukung format BCA REKENING TAHAPAN seperti
contoh yang digunakan untuk pengujian.

CATATAN PRIVASI:
PDF rekening koran contoh tidak disertakan ke dalam paket ini.
