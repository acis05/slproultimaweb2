StokLedger Pro Ultima v1.22.7

Pembaruan:
1. Impor master barang: Barcode opsional, kolom Barcode boleh kosong atau tidak ada.
2. Master jasa: Satuan tidak wajib dipilih; sistem memakai satuan internal default bila kosong.
3. Impor Kas/Bank + Saldo Awal: saldo awal membentuk jurnal Opening Balance sehingga muncul di Neraca; impor ulang juga memperbaiki data lama yang belum memiliki jurnal opening.
4. Laporan Rincian Penjualan dan Rincian Pembelian dengan pemilihan field/kolom dinamis dan ekspor mengikuti field terpilih.
5. Laporan History Pesanan Penjualan dan History Pesanan Pembelian.
6. Laporan DP Pembelian dan Alokasi DP Pembelian.
7. Laporan DP Penjualan dan Alokasi DP Penjualan.
8. Pro Ultima: Owner Mobile Cloud menambahkan Laba Rugi per Proyek dan Ringkasan Proyek.

Catatan: backup database sebelum upgrade dan lakukan Ctrl+F5 setelah server versi baru dijalankan.
