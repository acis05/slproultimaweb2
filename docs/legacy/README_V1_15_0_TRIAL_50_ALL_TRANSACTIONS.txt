StokLedger v1.15.0 - Trial 50 Semua Transaksi

- Trial maksimal 50 transaksi total.
- Input manual dan impor transaksi memakai kuota yang sama.
- Smart Import rekening koran menghitung setiap baris yang diposting.
- Import penjualan, pembelian, kas/bank, dan jurnal menghitung setiap dokumen.
- Pesanan penjualan/pembelian dan transfer gudang juga dihitung.
- Master data tanpa transaksi tidak mengurangi kuota.
- Hapus/void transaksi tidak mengembalikan kuota.
- Lisensi lifetime melalui dongle menonaktifkan pembatas transaksi.
