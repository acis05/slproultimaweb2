StokLedger Pro Ultima v1.19.0
Owner Dashboard Command Center
==============================================

Pembaruan sinkronisasi Owner Cloud untuk edisi Pro Ultima.

Data dashboard yang ditambahkan:
- Stok terlaris bulan ini
- Produk dengan margin terbesar
- Dead stock minimal 90 hari
- Reminder stok dan estimasi hari tersisa
- Piutang jatuh tempo 7 hari ke depan
- Hutang jatuh tempo 7 hari ke depan
- Top 5 biaya bulan ini
- Status bisnis dan aktivitas snapshot

Kompatibilitas:
- Owner Cloud Railway v1.19.0
- Identitas, lisensi, installer, database, dan fitur Pro Ultima tetap dipertahankan.

Cara penggunaan:
1. Jalankan StokLedger Pro Ultima v1.19.0.
2. Buka Owner Mobile Cloud.
3. Klik Sinkronkan Sekarang.
4. Buka dashboard Owner Cloud untuk melihat widget Command Center.
