STOKLEDGER PRO v1.4.4b — DOCUMENT DESIGNER PREVIEW FIX
=======================================================

Fokus versi ini hanya Menu Desain Dokumen.

PERBAIKAN
- Bagian Laporan Laba Rugi dan filter yang sebelumnya ikut tampil di atas
  halaman Desain Dokumen sekarang disembunyikan.
- Halaman Desain Dokumen hanya menampilkan editor desain dokumen.
- Setiap tab memiliki preview langsung.
- Preview berubah saat pengguna mengubah:
  judul, ukuran kertas, header, keterangan khusus, footer,
  penandatangan, logo, harga, SKU, satuan, gudang, diskon, dan pajak.
- Preview menggunakan data contoh sehingga desain dapat dilihat sebelum disimpan.
- Tombol Perbarui Preview tersedia.
- Surat Jalan dan Good Receive tetap tanpa harga.

Tidak ada perubahan pada transaksi, dashboard, laporan, atau impor Excel.
